# How To Schedule Your First Event

A scheduled event is the normal way to play on Slipmat: you pick a date and a time, Slipmat announces
it, and on the night you start and end it yourself.

It all happens on the **Schedule Event** page, <https://slipmat.io/artist/events/schedule/>. If you
have an artist profile you're ready — your streaming key came with it.

## Filling in the form

Stay on the **Live Streaming Event** tab and the **Set date** option. (The other tab is for events
that don't stream from Slipmat, and *Propose date(s)* lets your fans vote on a date instead of you
choosing one.)

- **Photo** — your artist's default event photo is used unless you pick one here.
- **Title** — what the event is called. Slipmat builds the event's Web address from it and shows the
  result under the field; use **edit** if you want a different one. The address is fixed once you
  save, so change it now if you're going to.
- **Labels** — at least one, no spaces in them. These are the genres and styles fans find your event
  by.
- **Description** — optional.
- **Visibility** — **Public** puts the event in Slipmat's listings. **Unlisted** keeps it out of
  them, but anyone with the link can still open it.
- **Date** and **Time** — events start on the hour, so you pick a date and an hour. The clock button
  switches between 24-hour and 12-hour time.
- **Song requests & Shout-outs** — off unless you turn it on. See
  [How To Set Up Song Requests](/howto/artist/set-up-requests/).

## Saving

**Save and Publish** announces the event; it needs a date and a time. **Save as Draft** keeps it to
yourself, with or without a date — nobody else sees a draft, and you publish it later from the
event's own page.

Either way you land on that event's page under **Events**, where you can edit it, open the public
page, cancel it or delete it.

::: tip One at a time
Schedule as many future events as you like — Slipmat only refuses two events starting at the same
time. Just remember that only one of them can be on the air at any moment.
:::

## Changing it afterwards

Edit anything from the event's page while it's still a draft or scheduled, the date and time
included. The Web address stays as you saved it.

Delete an event and it's gone. Once people have said they're coming, deleting is no longer possible —
**cancel** instead, which keeps the event listed as cancelled and tells everyone who signed up.

## What happens on the day

Half an hour before the start time Slipmat opens the doors by itself: the event moves into warmup and
its chat opens, so listeners can gather. That's when you connect your streaming software and take
over from the Stream Dashboard.
